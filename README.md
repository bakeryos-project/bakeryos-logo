# BakeryOS Logo & Branding Assets

This repository contains the official logos, icons, and branding assets for the BakeryOS operating system. It also includes the necessary packaging scripts to build and distribute the branding assets across the BakeryOS ecosystem.

---

## Repository Structure

The repository follows the standard Arch Linux packaging layout:

* **`usr/`**: Contains the actual branding assets mapped to the system root directory (e.g., icons, wallpapers, or system logos).
* **`PKGBUILD`**: The Arch Linux package build script used to compile and package the assets into a deployable archive.
* **`LICENSE`**: The GPL-3.0-or-later license file.
